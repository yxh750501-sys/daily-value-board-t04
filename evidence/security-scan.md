# 공개 안전 검사

- 실제 원천: Open-Meteo 공개 HTTPS 호출. API 키, 토큰, 계정 정보가 필요한 경로를 사용하지 않습니다.
- 브라우저 요청: Chromium 검사에서 Open-Meteo 요청 URL의 `key=`/`token=` 파라미터 0건.
- 코드·배포 파일: 비밀값 패턴을 검색했고 원문 비밀값 0건. `public-contract.json`의 금지 규칙 문장과 테스트 코드의 검사 문자열은 비밀값이 아닙니다.
- 공개 화면과 합성 자산: 실제 개인정보·개인 기록 0건. 합성 값은 실패 시험 영역에만 표시합니다.
- 실제 기온 기록: 각 방문자의 브라우저 IndexedDB에만 저장합니다. 원본 응답을 서버에 전송하거나 저장하지 않습니다.
